FEATURE VERIFICATION
================================================================================

✅ Dual Environments:
   - Backend services on separate ports (3001 vs 3011)
   - Indexer services on separate ports (3002 vs 3012)
   - Frontend services on separate ports (3000 vs 3010)
   - All services can run simultaneously

✅ Shared Infrastructure:
   - PostgreSQL (single instance, port 5432)
   - Redis (single instance, port 6379)
   - Nginx reverse proxy (ports 80/443)
   - Data consistency across environments

✅ Health Checks:
   - All services have HTTP /health endpoints
   - 10s interval, 5s timeout, 3 retries
   - 10s startup period before health checks begin

✅ Traffic Switching:
   - Dynamic routing via Nginx maps
   - No Nginx reload required
   - Instant switch between environments
   - Verification before switching

✅ Rollback Capability:
