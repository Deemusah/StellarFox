## 🚨 Important: To Run TypeScript Servers

**Node.js is NOT currently installed on this system.**

### Next Steps to Get TypeScript Running:

1. **Install Node.js** (required for both projects)
   ```
   Download from: https://nodejs.org/
   Recommended: LTS version 20.x or later
   ```

2. **Backend Setup**
   ```bash
   cd StellarFox-Backend
   npm install
   npm run dev
   ```
   This starts the TypeScript development server with hot reload.

3. **Frontend Setup**
   ```bash
   cd StellarFox-Frontend
   npm install
   npm run dev
   ```
   This starts the Next.js TypeScript development server.
